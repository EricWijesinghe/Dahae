Dahae server install file

Rent a server, make the setup text on this page, and paste it into the provider's server creation screen. The install then starts by itself.

1. What you need

  1. An Ubuntu 24.04 server from a hosting provider (Debian 12 also works).
  2. The domain you will use (for example myshop.com). You can connect the domain after the server is created.
  3. An email address for notices.

2. Enter your details

Enter a ping address from a service such as healthchecks.io to be told whether the install succeeded or failed. Leave it empty if you have none.
This text contains the setup code. Use the code within 7 days to create the owner account. When you are done, close this page and delete the text you copied.

5. After the server starts

  1. Copy the server's public IP (static IP) from the provider's screen.
  2. In your domain's DNS screen, point the A records @ and www at that IP. It can take from a few minutes to an hour to take effect.
  3. After 10 to 30 minutes, open https://(your domain)/health in a browser. When you see {"ok":true} the install is done.
  4. Then open https://(your domain)/admin/ and create the owner account with the setup code above.
Opening the address several times before the domain is connected is fine. But certificate requests must pause after repeated failures, so the certificate can be delayed.

If the install does not seem to finish, open the server console (browser SSH) on the provider's screen and follow the "If something goes wrong" section of guide 09 (guide/09-install-by-cloud.md).
