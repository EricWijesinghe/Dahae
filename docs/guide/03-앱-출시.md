# 3. 앱 출시 (App Store · Google Play)

앱은 **DODA 가 자기 Codemagic 과 스토어 계정으로 직접 빌드해서 올려요** ([guide 11](11-앱-직접-빌드.md)). 개발사에 초대장을 보내지 않아요. 설치 담당이 할 일은 스토어 계정을 만드는 것이에요.
맥(Mac)도, 코드도, 빌드 프로그램도 필요 없어요.

계정은 반드시 **사업자 명의**로 만들어요 (스토어 정책 — 앱 주인이 사장님이 되도록).

## 준비물
| 계정 | 비용 | 소요 | 비고 |
|---|---|---|---|
| Apple Developer Program (**조직**) | 스토어 요금표 | 스토어 기준 | D-U-N-S 번호 필요 (무료 발급, 며칠 걸림) |
| Google Play Console (**조직**) | 스토어 요금표 | 스토어 기준 | 개인 계정은 출시 전 테스터 12명·14일 테스트가 의무라 조직 계정 권장 |

## A. Apple (한 번만)
1. developer.apple.com 에서 **조직**으로 가입 → 결제 → 승인 메일 기다리기
2. 개발사 초대는 없어요. 계정 소유자가 직접 앱 두 개와 APNs 키를 만들어요 ([guide 11](11-앱-직접-빌드.md) 4-1, 4-2)
3. 같은 화면 [통합] → [App Store Connect API] → [+] → 이름 `malkkeum_asc`, 역할 **앱 관리**
   - 내려받은 `.p8` 파일, **Issuer ID**, **Key ID** 를 Codemagic 에 직접 넣어요 ([guide 11](11-앱-직접-빌드.md) 3-1). 개발사에 보내지 않아요 (아래 "키 보관")

## B. Google (한 번만)
1. play.google.com/console 에서 **조직** 계정으로 가입 → $25 결제 → 신원 확인
2. [사용자 및 권한] → 개발사 초대는 없어요. Play 서비스 계정 키를 DODA 가 만들어 **출시 관리자(Release manager)** 권한을 주고 ([guide 11](11-앱-직접-빌드.md) 4-3)
3. 앱 두 개 (다해 / 다해 파트너)도 DODA 가 직접 만들어요 (같은 곳, guide 11 4-3)

## 키 보관
`.p8` 파일과 서비스 계정 키는 비밀번호와 같아요. 저장소, 카카오톡 단체방, 이메일 본문에 올리지 마세요. Codemagic 과 서버 콘솔에만 직접 넣고, 파일 사본은 비밀번호 관리 앱에 보관하세요 (guide 11 §0).

## B-2. 간편 로그인 · 알림 (선택)
카카오·네이버·구글 로그인과 앱 알림을 쓰려면, 각 개발자 사이트에 **사업자 명의**로 앱을 DODA 가 직접 등록해요 ([guide 11](11-앱-직접-빌드.md) 4-4~4-7). 키 입력과 빌드도 DODA 가 해요.

## C. DODA 가 하는 것 ([guide 11](11-앱-직접-빌드.md))
- 저장소 포크, Codemagic 설정, 앱 두 개 등록 (다해 / 다해 파트너), 서버 주소(도메인)에 맞춰 빌드, 서명, 업로드
- 아이폰: **TestFlight** 로 올라간 빌드를 아이폰에서 "TestFlight" 앱으로 설치해 확인
- 안드로이드: Play **내부 테스트** 트랙의 초안을 확인해 휴대폰에서 설치해 확인
- 확인이 끝나면 DODA 가 심사 제출

## D. 심사 때 사장님/설치 담당이 할 일
- **심사용 계정**: 심사원은 한국 문자를 받을 수 없어요. 콘솔 [설정] → [스토어 심사용 데모 계정]에서 번호와 6자리 코드를 정해 켜고, 그 번호와 코드를 심사 메모에 직접 적어요. 개발사에 알려 주지 않아요. 14일 뒤 자동으로 꺼져요.
- 개인정보처리방침 주소: `https://도메인/privacy.html`, 계정 삭제 안내: `https://도메인/delete-account.html` (서버 설치 후 자동으로 생겨요)
- 스토어 설명 문구·데이터 보안 답변은 이 안내서 묶음의 `store/` 폴더에 있어요

심사 기간은 스토어 정책에 따라요. 승인되면 콘솔 [설정 → 사업장 정보 → 앱 스토어 주소]에 스토어 주소를 넣어 웹사이트 버튼을 켜세요.

## E. 스토어 사진 · 설명 문구
- 스토어 화면 사진은 `docs/store/screenshots/` 에 이미 만들어져 있어요 (고객·파트너 앱, 아이폰·아이패드·안드로이드 크기, 한국어·영어·일본어·중국어·베트남어).
- 화면이 바뀌면 DODA 가 포크에서 직접 다시 만들어요: `scripts/store/generate.sh`
- 설명 문구는 `docs/store/listing-*.md` 에 있고, 글자 수 제한은 `docs/store/check_listings.py` 로 확인해요.
- 개인정보 답변: Google 은 `docs/store/data-safety.md`, Apple 은 `docs/store/app-privacy.md`.
- 그 밖의 스토어 질문(광고, 대상 연령, 연령 등급, 금융 기능, 권한) 답변: Google 은 `docs/store/play-declarations.md`, Apple 은 `docs/store/app-privacy.md` 2·3항, 심사 메모는 `docs/store/review-notes.md`.

## 앱 업데이트
DODA 가 포크에서 새 태그를 만들고 Codemagic 을 다시 실행해요 ([guide 11](11-앱-직접-빌드.md) 8번). 스토어 심사와 출시가 끝나면 휴대폰이 자동으로 업데이트해요.
