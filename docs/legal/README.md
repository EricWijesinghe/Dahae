## 한국어

- **공개 저장소는 사용 허락이 아닙니다.** 소스를 보거나, 복제하거나, 빌드하거나, 내려받아도 어떤 사용 권리도 생기지 않습니다. 사용 권리는 저작권자와 맺은 서면 계약으로만 생깁니다.
- **계약서 양식은 템플릿입니다.** 대괄호 `[ ]` 안의 항목을 채워야 합니다. 서명 전에 반드시 한국 변호사의 검토를 받으세요. 양식만 쓰면 법적 효력이나 보호가 보장되지 않습니다.
- **개인정보.** 라이선시가 자신의 서버에서 고객 데이터를 처리하면, 라이선시가 「개인정보 보호법」상 개인정보처리자입니다. 저작권자가 서버나 데이터에 접근하는 지원을 하면 업무위탁 계약이 따로 필요합니다 (계약서 제8조).
- **상표.** "Dahae", "다해" 및 다해 로고는 저작권자의 상표(™)입니다. 등록 여부는 이 문서에서 주장하지 않습니다.
- **문의.** 라이선스, 사용 허가, 계약 문의: EricWijesinghe@hotmail.com
- **보안 신고.** 보안 취약점은 공개 이슈가 아니라 [SECURITY.md](../../SECURITY.md)에 따라 비공개로 신고하세요.

If the copyright holder gives support access to those servers or data, a separate processing entrustment agreement is needed (agreement Article 8).
