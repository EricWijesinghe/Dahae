# 30. 용어 풀이 (한영)

**이 장에서 할 일:** 이 매뉴얼과 콘솔에 나오는 어려운 말을 쉬운 말로 찾아봐요. 영어 이름도 함께 적어서, 영어 화면이나 개발자와 이야기할 때도 쓸 수 있어요.

> **준비물**
>
> - 없어요. 모르는 말이 나올 때마다 이 장을 펼치세요.

굵은 글씨는 콘솔 화면에 그대로 나오는 이름이에요.

## 30.1 사람과 계정

| 용어 | 영어 | 쉬운 뜻 | 나오는 장 |
|---|---|---|---|
| **소유자** | **Owner** | 회사에 한 명만 있는 최고 관리자예요. 결제 카드 잠금 해제, 서버 업데이트, 소유자 넘기기를 할 수 있어요. 보통 사장님이에요 | 6, 8 |
| **관리자** | **Admin** | 모든 메뉴와 설정을 볼 수 있는 직원 계정이에요 | 8, 20 |
| **상담원** | **Consultant** | 예약과 상담만 다루는 직원 계정이에요. 설정, 직원, 재무 등은 안 보여요 | 8, 20 |
| 파트너 (기사님) | Partner (pro) | 청소를 하러 가는 사람이에요. 파트너 앱을 써요 | 20, 24 |
| 팀원 | Team member | 파트너가 초대한 사람이에요. 사장님이 승인해야 일을 받아요 | 20 |
| 고객 | Customer | 고객 앱이나 웹사이트로 예약하는 사람이에요 | 24 |
| 개발자 (설치 담당) | Developer (installer) | 서버를 설치하고 서버 명령을 쳐 주는 사람이에요 | 3, 33 |

## 30.2 로그인과 보안

| 용어 | 영어 | 쉬운 뜻 | 나오는 장 |
|---|---|---|---|
| **설치 코드** | **Setup code** | 사장님 계정을 처음 만들 때 한 번 쓰는 12자리 코드예요 (`XXXX-XXXX-XXXX`). 7일 동안 써요 | 6 |
| 인증 앱 | Authenticator app | 휴대폰에서 30초마다 바뀌는 6자리 숫자를 보여 주는 앱이에요 (예: Google Authenticator) | 6 |
| **2단계 인증** | **Two-step sign-in** | 비밀번호에 더해 인증 앱의 6자리를 한 번 더 넣는 로그인이에요. 끌 수 없어요 | 6 |
| **복구 코드** | **Recovery codes** | 휴대폰을 잃었을 때 인증 앱 대신 쓰는 코드 10개예요. 하나에 한 번씩 써요 | 6, 29 |
| 소유자 코드 (**사장님 인증 코드**) | Owner code (**Owner authenticator code**) | 소유자 휴대폰 인증 앱의 6자리예요. 잠금 해제나 업데이트 때 물어봐요 | 9, 26 |
| 최근 재인증 | Step-up | 지급이나 개인정보 같은 중요한 일을 할 때, 5분 안에 인증 앱 코드를 한 번 더 확인하는 것이에요 | 8, 21 |
| 비밀번호 관리 앱 | Password manager | 비밀번호와 키를 암호화해 보관하는 앱이에요 | 32 |
| **모든 기기에서 로그아웃** | **Sign out everywhere** | 내 계정으로 로그인된 모든 PC·휴대폰을 한 번에 로그아웃시켜요 | 8, 29 |

## 30.3 설정 화면

| 용어 | 영어 | 쉬운 뜻 | 나오는 장 |
|---|---|---|---|
| 설정 카드 | Setup card | **[설정]** 화면에서 회사 서비스 하나를 연결하는 칸이에요 | 9 |
| **잠김** / **잠금 해제 (소유자 코드)** | **Locked** / **Unlock (owner code)** | 저장한 카드는 잠겨요. 소유자만 5분 동안 풀 수 있어요 | 9 |
| **연결 확인** | **Check connection** | 저장한 키로 그 회사 서비스에 실제로 연결되는지 시험해요. 결제 카드에서는 **API 키 확인** 이에요 | 9 |
| **테스트** / **실거래** | **Test** / **Live** | 테스트 키는 돈이 움직이지 않는 시험용, 실거래(라이브) 키는 진짜 돈이 오가는 키예요 | 11, 12 |
| 키 | Key | 회사 서비스가 우리 서버를 알아보게 하는 긴 비밀 글자예요 | 9 |

## 30.4 결제와 돈

| 용어 | 영어 | 쉬운 뜻 | 나오는 장 |
|---|---|---|---|
| PG (결제대행사) | Payment gateway | 카드·간편결제를 대신 받아 주는 회사예요. 다해는 PortOne, 토스페이먼츠, 또는 둘 다 쓸 수 있어요 | 11, 12 |
| 채널 키 | Channel key | PortOne 에서 결제 수단(카드사 등)마다 받는 키예요. `channel-key-` 로 시작해요 | 11 |
| 웹훅 | Webhook | 결제사가 "결제됐어요" 를 우리 서버에 자동으로 알려 주는 연락이에요 | 11, 12, 29 |
| 웹훅 시크릿 / 보안 키 | Webhook secret / Security key | 그 연락이 진짜 결제사가 보낸 것인지 확인하는 비밀 값이에요 | 11, 12, 13 |
| 결제 대사 | Payment reconciliation | 결제사 기록과 우리 기록을 서로 맞춰 보는 일이에요 | 21, 26 |
| **정산** | **Settlements** | 파트너에게 줄 돈을 계산하는 일이에요 | 21 |
| 지급 | Payout | 정산된 돈을 파트너 계좌로 보내는 일이에요 | 13, 21 |
| **직접 이체** / **토스 지급대행** | **Manual transfer** / **Toss payouts** | 사장님이 은행에서 직접 보내는 방식 / 토스가 대신 보내 주는 방식이에요 | 13 |
| 원천징수 | Withholding | 파트너에게 줄 돈에서 세금을 미리 떼어 두는 것이에요 | 21 |
| 현금영수증 | Cash receipt | 계좌이체 같은 현금 결제에 발급하는 영수증이에요 | 21 |
| 세금계산서 | Tax invoice | 사업자 고객에게 발행하는 세금 서류예요. 홈택스에서 발행해요 | 21 |

## 30.6 서버와 인터넷 주소

| 용어 | 영어 | 쉬운 뜻 | 나오는 장 |
|---|---|---|---|
| 서버 | Server | 다해 프로그램과 데이터가 들어 있는 인터넷의 컴퓨터예요 | 3~7 |
| 도메인 | Domain | 사이트 주소예요 (예: `example.co.kr`). 콘솔에서 바꿀 수 있어요 | 5, 28 |
| **예전 주소** | **Old addresses** | 도메인을 바꾼 뒤에도 계속 응답하는 예전 도메인이에요. 직접 닫을 때까지 설치된 앱이 그대로 써요 | 28 |
| **서버 승인 코드** | **Server approval code** | 도메인 바꾸기 같은 큰 작업에 사장님 코드와 따로 넣는, 서버가 직접 확인하는 두 번째 6자리 코드예요 | 26, 28 |
| **짧은 이름** | **Short name** | 12자 이내의 서비스 이름이에요. 문자 앞머리, 결제 이름, 휴대폰 홈 화면 앱 이름에 써요 | 28 |
| **스토어 앱 빌드** | **Store app build** | 앱 이름·아이콘·앱 ID 처럼 스토어 앱에 들어가 있어 새 빌드를 올려야 바뀌는 것을 알려 주는 카드예요 | 25, 28 |
| DNS | DNS | 도메인을 서버 IP 로 바꿔 주는 인터넷 전화번호부예요 | 5 |
| A 레코드 | A record | DNS 에 "이 도메인은 이 IP 예요" 라고 적는 한 줄이에요 | 5 |
| 공인 IP | Public IP | 인터넷에서 서버를 찾는 숫자 주소예요 (예: `203.0.113.10`) | 4, 5 |
| HTTPS / 인증서 | HTTPS / Certificate | 주소창의 자물쇠예요. 서버가 자동으로 받고 갱신해요 | 5 |
| CloudShell | CloudShell | AWS 웹 화면 안에서 명령을 치는 검은 창이에요 | 3, 4 |
| IAM | IAM | AWS 에서 사람과 권한을 관리하는 곳이에요 | 3 |
| MFA | MFA | AWS 로그인의 2단계 인증이에요 | 3 |
| CloudFormation 스택 | CloudFormation stack | AWS 에 서버와 필요한 것들을 한 번에 만들어 주는 묶음이에요. 끝나면 `CREATE_COMPLETE` 가 나와요 | 4 |
| Session Manager | Session Manager | SSH 없이 AWS 웹 화면에서 서버 명령 창을 여는 기능이에요 | 5, 29 |
| `dahae` 명령 | `dahae` command | 서버에서 개발자가 쓰는 관리 명령이에요 (예: `sudo dahae status`) | 33 |

## 30.7 백업, 업데이트, 상태

| 용어 | 영어 | 쉬운 뜻 | 나오는 장 |
|---|---|---|---|
| 백업 | Backup | 데이터의 사본이에요. 매일 새벽 3시 30분에 만들어요 | 27 |
| 외부 백업 | Offsite backup | 서버 밖 저장소에 둔 백업 사본이에요 | 17, 27 |
| S3 호환 저장소 / 버킷 | S3-compatible storage / Bucket | 외부 백업을 넣는 인터넷 파일 창고(Cloudflare R2 등)와 그 안의 폴더예요 | 17 |
| 비밀 키 사본 | Secret key copy | 서버의 비밀 키를 비밀번호로 잠근 파일이에요. 없으면 외부 백업을 못 열어요 | 27 |
| `DATA_KEY` | `DATA_KEY` | 연동 키와 백업을 잠그는 서버의 비밀 키예요. 바꾸거나 지우면 안 돼요 | 27, 33 |
| 복원 | Restore | 데이터를 백업 시점으로 되돌리는 일이에요. 그 뒤의 데이터는 사라져요 | 27 |
| 되돌리기 | Rollback | 프로그램만 바로 전 버전으로 되돌리는 일이에요. 데이터는 그대로예요 | 26, 33 |
| **업데이트** | **Update** | 서버 프로그램을 새 버전으로 바꾸는 일이에요. 매주 월요일 새벽 4시에 자동으로 해요 | 26 |
| 안정 / 베타 채널 | Stable / beta channel | 업데이트를 받는 줄이에요. 손님을 받는 서버는 안정(stable)이에요 | 33 |
| **시스템 상태** | **System status** | 서버와 연결 서비스가 건강한지 보여 주는 콘솔 화면이에요 | 26 |
| **업타임 하트비트** | **Uptime heartbeat** | 서버가 "살아 있어요" 신호를 바깥 서비스에 보내는 것이에요. 끊기면 그 서비스가 알려 줘요 | 17 |
| **점검 모드** | **Maintenance mode** | 앱 화면 위쪽에 점검 안내를 띄우고 새 예약을 막는 스위치예요. 앱과 콘솔은 계속 돼요 | 26 |
| **기능 스위치** | **Feature switches** | 예약·채팅·AI 상담·결제를 따로 끄고 켜는 스위치예요 | 26 |
| **백그라운드 작업** | **Background jobs** | 서버가 보이지 않는 곳에서 정해진 시간마다 하는 일이에요 | 26 |
