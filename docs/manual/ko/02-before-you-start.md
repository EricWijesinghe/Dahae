# 02. 시작 전에 준비할 것

## 이 장에서 할 일

설치를 시작하기 전에 필요한 **계정, 서류, 앱**을 모으고, 오래 걸리는 심사를 먼저 신청해요. 이 장을 끝내면 설치 중간에 멈추는 일이 거의 없어요.

## 준비물

- 사업자등록증 (사진이나 PDF)
- 회사 이메일 주소 하나 (모든 계정 가입에 같은 주소를 쓰면 관리가 쉬워요)
- 휴대폰 1대 (인증 앱을 설치할 사장님 휴대폰)
- 결제 수단 (클라우드 요금을 낼 카드)

## 2.1 휴대폰에 앱 두 개 설치하기

1. 사장님 휴대폰에서 **앱 스토어**(아이폰) 또는 **Play 스토어**(안드로이드)를 열어요.
2. **인증 앱**을 설치해요. 예: Google Authenticator, 1Password 같은 앱이에요. 콘솔에 로그인할 때 6자리 코드를 보여 줘요.
3. **비밀번호 관리 앱**을 하나 정해요. 계정 비밀번호, 복구 코드, 키 사본 비밀번호를 여기에 보관해요.

**이렇게 보이면 성공:** 휴대폰 홈 화면에 인증 앱 아이콘이 있어요.

> **주의** 비밀번호, 설정 키, 복구 코드는 **카카오톡, 문자, 이메일 본문, 문서에 적지 마세요.** 비밀번호 관리 앱에 저장하고, 꼭 전해야 하면 전화처럼 다른 경로로 전하세요.

## 2.2 계정 준비 목록

계정은 모두 **회사(사업자) 이름**으로 만드세요. 개발자에게는 관리자 권한만 줘요. 아래 표를 인쇄해서 하나씩 표시하면 편해요.

| 확인 | 계정 | 무엇에 쓰나요 | 누가 만드나요 | 언제 필요한가요 | 이 책의 장 |
|---|---|---|---|---|---|
| ☐ | **AWS 계정** (결제 수단 등록 완료) | 서버를 빌려요 | 사장님 | 설치 전 | 3장 |
| ☐ | **도메인** (예: `example.co.kr`) | 고객과 직원이 들어오는 주소 | 사장님과 개발자가 함께 정해요 (등록 · DNS 는 Cloudflare 계정에서 할 수 있어요) | 설치 전 | 5장 |
| ☐ | **인증 앱** | 콘솔 2단계 인증 | 사장님 휴대폰 | 설치 직후 | 6장 |
| ☐ | **PortOne** (결제) + PG 계약 | 고객 결제 (PortOne과 토스페이먼츠 중 하나 이상), 본인확인 (PASS는 PortOne이 있어야 해요) | 사장님 | 영업 전 (심사 오래 걸림) | 11장 |
| ☐ | **토스페이먼츠** (선택) | 결제 (단독 또는 PortOne과 함께), 파트너 자동 지급 | 사장님 | 영업 전 (토스페이먼츠로 결제를 받을 때) | 12장, 13장 |
| ☐ | **Solapi** (문자) + 발신번호 | 문자, 알림톡 | 사장님 | 영업 전 (발신번호 등록 오래 걸림) | 14장 |
| ☐ | **카카오톡 채널** (알림톡, 선택) | 카카오 알림톡 | 사장님 | 알림톡을 쓸 때 | 14장 |
| ☐ | **Firebase** (Google 계정) | 앱 푸시 알림 | 사장님 (개발자에게 접근 권한) | 앱 출시 전 | 16장 |
| ☐ | **카카오 · 네이버 · 구글 · 애플 개발자 계정** | 간편 로그인 | 사장님 | 앱 출시 전 | 15장 |
| ☐ | **Google Play Console** (조직) | 안드로이드 앱 출시 | 사장님 (개발자를 관리자로 초대) | 앱 출시 전 | 25장 |
| ☐ | **Apple Developer Program** (조직) | 아이폰 앱 출시 | 사장님 (개발자를 Admin 으로 초대) | 앱 출시 전 | 25장 |
| ☐ | **외부 백업 저장소** (Cloudflare R2, 네이버 클라우드 Object Storage 등) | 서버 밖 백업 | 사장님 | 설치 직후 권장 | 17장 |
| ☐ | **가동 확인 서비스** (healthchecks.io 등) | 서버가 멈추면 알려 줘요 | 사장님 | 설치 직후 권장 | 17장 |
| ☐ | **비밀번호 관리 앱** | 비밀 값 보관 | 사장님 | 처음부터 | 2.1 |

> **팁** Google Play 와 Apple 조직 가입에는 **D-U-N-S 번호**가 필요해요. 발급에 시간이 걸릴 수 있으니 미리 신청하세요 (기간은 발급 기관 기준이에요).

## 2.3 서류 준비 목록

| 확인 | 서류 | 어디에 쓰나요 |
|---|---|---|
| ☐ | 사업자등록증 | 결제(PG) 심사, 발신번호 등록, 카카오 채널, 스토어 조직 가입, 콘솔의 사업장 정보 |
| ☐ | 통신판매업 신고증 | 콘솔의 사업장 정보 (웹사이트 아래쪽에 법에 따라 표시돼요) |
| ☐ | 발신번호 등록 서류 | Solapi 발신번호 등록. 필요한 서류는 Solapi 안내를 따르세요 |
| ☐ | 로고 이미지 파일 | 콘솔의 사업장 정보, 앱 머리말, 웹사이트 |
| ☐ | 고객센터 전화번호, 이메일, 운영 시간 | 콘솔의 사업장 정보 |

## 2.4 비용 안내

이 책에는 가격을 적지 않아요. 요금은 회사마다 자주 바뀌기 때문이에요. 아래 표의 곳에서 직접 확인하세요.

| 항목 | 비용 확인하는 곳 |
|---|---|
| AWS 서버 | AWS 요금 계산기 (https://calculator.aws/) 에서 **서울(ap-northeast-2)** 지역으로 계산하세요. 서버 종류, 디스크 크기, 데이터 전송량, 스냅샷 양에 따라 달라요 |
| 다른 클라우드 서버 | 업체 요금표 |
| 도메인 | 등록 업체 요금표 |
| 결제 (PortOne, PG, 토스페이먼츠) | 각 회사 요금(수수료)표 |
| 문자 · 알림톡 (Solapi) | Solapi 요금표. 알림톡이 실패하면 SMS 로 대신 보내는데, SMS 가 알림톡보다 비싸요 |
| 외부 백업 저장소 | 각 서비스 요금표. Cloudflare R2 나 네이버 클라우드 Object Storage 는 백업 몇 개 분량이면 월 몇 천 원 수준이에요 |
| Apple Developer Program | 연 99 USD (조직) |
| Google Play Console | 업체 요금표 |

> **참고** AWS 의 고정 IP(Elastic IP)는 서버에 연결되어 있을 때는 따로 비용이 없고, 연결이 끊기면 요금이 붙어요.

## 2.5 오래 걸리는 심사부터 신청하기

아래는 회사 심사를 기다려야 해서 며칠이 걸릴 수 있어요. **설치 전에 먼저 신청**하세요. 기다리는 동안 설치와 다른 설정을 할 수 있어요.

1. 결제를 어디로 받을지 정해요: PortOne, 토스페이먼츠, 또는 둘 다. 하나 이상은 있어야 해요. 본인인증(PASS)은 PortOne이 있어야 해요.
   - PortOne을 쓰면: **PortOne 가입과 PG사 심사** 를 신청해요. (기간은 회사 기준)
2. 토스페이먼츠를 쓰면: **토스페이먼츠 전자결제 계약** 을 신청해요. 저장 카드나 정기 방문을 쓰려면 **자동결제 계약**도 같이 신청해요.
3. **Solapi 가입과 발신번호 등록** 을 신청해요.
4. **카카오톡 채널** 을 개설하고 알림톡 템플릿 심사를 신청해요 (14장). 카카오 심사는 보통 영업일 기준 며칠이 걸려요.
5. **D-U-N-S 번호, Google Play 조직, Apple 조직** 가입을 신청해요.

**이렇게 보이면 성공:** 각 회사에서 "신청 완료" 또는 "심사 중" 안내를 받았어요.

## 2.6 일정 예시

아래는 계획에 적힌 예시 일정이에요. 실제 기간은 각 회사 심사에 따라 달라요.

| 날 | 누가 | 할 일 |
|---|---|---|
| 0일 | 사장님 | 라이선스 계약 서명, 도메인 정하기, AWS 담당 계정 만들기 (3장), Play · Apple 조직 가입, 개발자를 관리자로 초대, Firebase · 카카오 · PortOne 또는 토스페이먼츠(둘 다도 돼요) · Solapi 가입 |
| 0일 | 개발자 | 라이선스 계약 확인, 배포 준비 |
| 0–1일 | 개발자 · 사장님 | 서버 만들기 (4장, 개발자), 사장님 계정과 설정 (6장 · 3부, 사장님이 하고 개발자가 통화로 안내) |
| 1일 | 개발자 | 앱 빌드와 첫 업로드 |
| 1–3일 | 직원 · 개발자 | 안드로이드 · 아이폰 실기기 테스트 (로그인, 사진, 결제 창, 푸시, 위치) |
| 심사 제출 때 | 관리자 · 개발자 | 심사용 데모 계정 켜기 (17장), 심사 메모, 제출 |
| 심사 기간 | 스토어 | Google 은 보통 며칠, Apple 은 보통 1–3일 (보장되지 않아요) |

> **주의** 서면 라이선스 계약에 서명하기 전에는 개발자가 빌드나 배포를 하지 않아요.

## 자주 생기는 문제

| 이런 일이 있으면 | 이렇게 하세요 |
|---|---|
| 어떤 계정을 누구 이름으로 만들지 모르겠어요 | 모두 회사(사업자) 이름으로 만드세요. 개발자에게는 관리자 권한만 줘요 |
| 결제 심사가 아직 안 끝났어요 | 괜찮아요. 서버 설치와 다른 설정을 먼저 하세요. 결제 카드는 심사가 끝난 뒤 연결해요 |
| 비밀번호를 개발자에게 어떻게 보내야 할지 모르겠어요 | 채팅으로 보내지 말고, 전화로 불러 주거나 비밀번호 관리 앱의 공유 기능을 쓰세요 |
| 인증 앱을 무엇으로 할지 모르겠어요 | Google Authenticator 처럼 널리 쓰는 앱이면 돼요. 휴대폰을 바꿀 때 옮기는 방법을 미리 알아 두세요 |
