# 31. 체크리스트

**이 장에서 할 일:** 출시 전, 매일, 매주, 매달, 매년 할 일을 한 장씩 모았어요. 인쇄해서 하나씩 체크하세요. 각 줄 끝의 숫자는 자세한 설명이 있는 장이에요.

> **준비물**
>
> - 이 장을 인쇄한 종이와 펜, 또는 체크할 수 있는 메모 앱.
> - 콘솔 관리자 계정 (소유자 계정이면 더 좋아요).

---

## 31.1 출시 전 체크리스트

### 서버 (개발자와 함께)

- [ ] 서버가 서울 지역에 있고, Ubuntu 24.04 예요 (4장, 7장).
- [ ] 도메인 A 레코드가 서버 공인 IP 를 가리켜요. Cloudflare 라면 회색 구름(DNS only)이에요 (5장).
- [ ] 브라우저에서 `https://도메인/health` 를 열면 `"ok":true` 가 들어간 글자가 보여요 (5장).
- [ ] 개발자의 `sudo dahae status` 에 `✔ 앱 정상` 과 `✔ HTTPS 정상` 이 나와요 (29장).
- [ ] 클라우드 방화벽에 필요한 포트만 열려 있어요. AWS 는 80, 443 만 (22 는 닫혀 있어요, 4장), 다른 클라우드는 22, 80, 443 만이에요 (7장).

### 사장님 계정과 보안

- [ ] 설치 코드로 **사장님 계정**을 직접 만들었어요. 개발자가 대신 만들지 않았어요 (6장).
- [ ] 사장님 휴대폰 인증 앱에 2단계 인증을 등록했어요 (6장).
- [ ] 복구 코드 10개를 **종이에** 적어 안전한 곳에 두었어요 (6장, 32장).
- [ ] 개발자가 만든 **비밀 키 사본**과 잠금 비밀번호를 서버 밖에 따로 보관했어요 (27장).
- [ ] 콘솔을 PC·휴대폰에 앱처럼 설치했어요 (6장).

### 설정 카드 (콘솔 **[설정]**)

- [ ] **사업장 정보**: 서비스 이름, 대표 색, 로고, 사업자 정보, 고객센터 번호 (10장).
- [ ] **결제 수단**: 계약된 수단만 켰어요 (10장).
- [ ] **결제 (PortOne)** 또는 **결제 (토스페이먼츠)**: 키 저장, **[API 키 확인]** 에서 **연결됨** (11장, 12장).
- [ ] 결제사 화면에 웹훅 주소를 넣었어요 (11장, 12장).
- [ ] **파트너 지급**: 직접 이체 또는 토스 지급대행을 골랐어요 (13장).
- [ ] **문자 · 알림톡 (Solapi)**: **연결됨**, 발신번호 승인, 알림톡 템플릿 승인 (14장).
- [ ] 쓰는 간편 로그인 카드(카카오, 네이버, 구글, 애플)를 채우고 앱에서 직접 로그인해 봤어요 (15장).
- [ ] **앱 푸시 알림 (Firebase)** 을 채웠어요 (16장).
- [ ] **주소 검색 (도로명주소)** 를 채웠어요 (16장).
- [ ] **외부 백업 (S3 호환)**: **[연결 확인]** 에서 **연결됨** (17장).
- [ ] **업타임 하트비트** 카드가 **연결됨** 이에요 (개발자에게 부탁) (17장).
- [ ] 저장한 카드는 저절로 잠겨요. 잠금을 풀었던 카드는 **[잠그기]** 로 다시 잠갔어요 (9장).

### 테스트 결제 (테스트 키로, 돈이 움직이지 않아요)

- [ ] 결제 수단마다 1번씩 결제해 봤어요 (12장).
- [ ] 1건 전액 환불, 1건 부분 환불을 해 봤어요 (12장, 21장).
- [ ] 결제창을 닫았을 때 앱이 결제 취소로 돌아와요 (12장).
- [ ] 안드로이드와 아이폰에서 카드사 앱·간편결제 앱으로 갔다가 앱으로 돌아와요 (12장).
- [ ] 결제사 화면의 웹훅 기록에서 우리 서버가 잘 받았어요 (12장).
- [ ] 테스트 결제를 모두 환불했어요.
- [ ] 라이브(실거래) 키로 바꾸고, 다시 **연결됨** 을 확인했어요 (11장, 12장).

### 운영 준비

- [ ] **[카탈로그 · 가격]** 에서 서비스와 가격을 확인했어요 (18장).
- [ ] **[시스템 상태]** → **알림 설정** 에서 **알림 받을 휴대폰** 을 넣고 **[저장]** 했어요 (26장).
- [ ] **[시스템 상태]** 에 빨강(**조치 필요**)이 없어요 (26장).
- [ ] 직원 계정을 만들고 역할(**관리자** / **상담원**)을 정했어요 (20장).
- [ ] **[운영 규칙]** 의 기본값을 한 번 읽어 봤어요 (23장).
- [ ] **[갱신 일정]** 에 도메인, 호스팅, Apple 개발자 계정, Solapi, 외부 백업 저장소, 비밀 키 사본 확인(종류 **기타**) 날짜를 넣었어요 (23장, 27장).

### 스토어 출시 (25장)

- [ ] **[설정]** → **스토어 심사용 데모 계정** 을 켜고 기간을 정했어요 (17장).
- [ ] 파트너 심사용 계정을 **승인** 했어요 (20장, 25장).
- [ ] 심사가 끝나면 데모 계정을 끄거나 기간이 끝났는지 확인해요 (17장).
- [ ] 애플 로그인을 쓰면 애플 카드의 키와 서버 알림 주소를 등록했어요 (15장).

## 31.2 매일 (아침 5분)

- [ ] **[대시보드]**: 오늘 작업, 견적 대기, 미배정, 안 읽은 상담 숫자를 봐요 (19장).
- [ ] 미배정이 있으면 **[예약]** 에서 열어 파트너에게 연락하거나 일정을 조정해요 (19장).
- [ ] 안 읽은 상담은 **[상담함]** 에서 답장해요 (19장).
- [ ] **[견적 데스크]** 에 새 요청이 있으면 견적을 보내요 (19장).
- [ ] 휴대폰에 운영 알림 문자가 왔으면 **[시스템 상태]** 를 열어 봐요 (26장).

## 31.3 매주 (10분)

- [ ] **[시스템 상태]** 에서 빨강·노랑 항목을 봐요. 노랑이 쓰지 않는 서비스의 **설정 안 됨** 뿐이면 괜찮아요 (26장).
- [ ] **자동 백업** 이 초록이고 **마지막 백업** 이 하루 안이에요 (27장).
- [ ] **외부 서비스** 의 **외부 백업 (S3 호환)** 이 최근 성공이에요 (27장).
- [ ] **서버 디스크** 여유가 20% 이상이에요 (26장).
- [ ] **최근 서버 작업** 에 **실패** 가 없어요. 월요일 자동 업데이트 뒤 **버전** 을 확인해요 (26장).
- [ ] **[정산]** 에서 지급할 건을 처리해요 (21장).
- [ ] **앱 오류 보고** 에 같은 오류가 많으면 개발자에게 보내요 (26장).

## 31.4 매달 (30분)

- [ ] 외부 백업 점검: 소유자 계정으로 **외부 백업 (S3 호환)** 카드의 **[연결 확인]** → **연결됨**. 잠금은 풀지 않아도 돼요 (27장).
- [ ] 개발자에게 외부 백업 목록에 어젯밤 파일이 있는지 확인해 달라고 해요 (27장).
- [ ] **[갱신 일정]** 에서 이번 달과 다음 달에 갱신할 것을 확인해요 (23장).
- [ ] **[활동 기록]** 에서 지난달 기록을 훑어보고, 모르는 일이 있으면 개발자에게 물어요 (23장).
- [ ] **[직원]** 에서 그만둔 사람의 계정을 **[비활성화]** 했어요 (20장).
- [ ] **[탈퇴·개인정보 요청]** 에 처리 안 된 요청이 없어요 (23장).
- [ ] 테스트로 만든 결제·환불이 남아 있지 않아요 (21장).
- [ ] 결제사(PortOne, 토스페이먼츠)와 Solapi 의 이번 달 요금을 확인해요. 금액은 각 회사 요금표를 따라요.

## 31.5 매년, 또는 갱신 때

- [ ] 도메인 갱신 (만료되면 사이트가 안 열려요).
- [ ] 호스팅(서버 비용) 결제 수단 확인.
- [ ] Apple 개발자 계정 갱신.
- [ ] 외부 백업 저장소 결제와 접근 키 확인.
- [ ] **비밀 키 사본 확인**: 사본 파일과 잠금 비밀번호가 둘 다 있는지 봐요 (27장).
- [ ] 복구 코드 종이가 그대로 있는지 봐요 (32장).
- [ ] 개발자와 시험 서버에서 실제 복원 연습을 해요 (27장).
- [ ] 부가가치세 신고 기한을 세무 담당자와 확인해요. **부가가치세 신고 기한 임박** 알림을 켜 두세요 (26장).

## 31.6 수동 업데이트 전후

- [ ] 손님이 적은 시간이에요.
- [ ] **[시스템 상태]** 에 빨강이 없어요.
- [ ] 소유자 휴대폰 인증 앱이 손에 있어요.
- [ ] **[지금 업데이트]** → 6자리 → **[계속]** (26장).
- [ ] **최근 서버 작업** 이 **완료** 가 됐어요.
- [ ] **버전** 이 바뀌었고 **가동 시간** 이 짧아졌어요.
- [ ] 고객 앱에서 예약 화면이 열려요.

## 31.7 직원이 그만둘 때

- [ ] **[직원]** 에서 그 사람을 **[비활성화]** 해요 (20장).
- [ ] 그 사람이 소유자라면, 먼저 **[내 계정]** → **[소유자 넘기기]** 로 다른 관리자에게 넘겨요 (8장).
- [ ] 그 사람이 알던 회사 서비스 비밀번호(결제사, Solapi, 도메인 회사 등)를 바꿔요 (32장).
- [ ] 그 사람이 키를 다뤘다면 키를 새로 발급해 **[설정]** 에 다시 넣어요 (29장 29.9).

## 자주 생기는 문제

> **자주 생기는 문제**
>
> - **체크가 안 되는 항목이 있어요** → 그 줄 끝의 장을 펼쳐 순서대로 다시 하세요. 그래도 안 되면 29장을 보세요.
> - **매주 점검을 자꾸 잊어요** → 휴대폰 달력에 매주 같은 요일 알림을 넣어 두세요.
